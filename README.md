# Dubai Trip Assistant AI

## Description
AI-powered chatbot for planning a trip to Dubai. Built using Python, OpenAI's GPT-4 model, and Streamlit, the chatbot assists users by providing travel recommendations, a day-wise itinerary, and answering their queries regarding Dubai’s tourism, locations, food, events, and more. The assistant's name is ROBO and it interacts with users in a professional and helpful manner.

## Features
- Personalized trip planning and itinerary suggestions for Dubai.
- Answers to user queries about Dubai's tourism, hotels, food, events, etc.
- Integration of OpenAI's GPT for intelligent conversation and responses.
- Built with Python and Streamlit for a smooth user interface.

## Prerequisites
Make sure you have the following installed:
- Python (preferably Python 3.x)
- OpenAI API Key (for accessing GPT-4)
- Streamlit for creating the web app interface
- `python-dotenv` for environment variable management
